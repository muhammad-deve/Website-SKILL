# Visual critique

Keep measured failures separate from visual concerns. Rank the most consequential
issues first. Record a specific hypothesis for each iteration, what changed, and
whether the subsequent capture supports it. Unobserved dimensions stay unreviewed.

Delivery: objective gate result, manual tasks exercised, visual assessment and
remaining limitations. A numerical average cannot certify beauty.
