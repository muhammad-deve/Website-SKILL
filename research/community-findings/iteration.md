# Community lesson: a reference needs operational detail

Read 2026-11-12: [developer discussion](https://www.reddit.com/r/ClaudeCode/comments/1w8udmf/functionality_is_such_a_breeze_while_design_is_so/).
This is a small, self-selected anecdotal sample, not an evaluation of model quality.

Participants describe progress after specifying individual reference qualities
(palette, fonts and layout), and after asking an agent to check consistency with a
design system. Other comments report repetitive results despite skill use. The thread
does not control model, budget, brief, reference quality or reviewer preference.

Actionable hypothesis: a persistent direction record plus a concrete browser defect
is easier to act on than a broad request to make a page feel expensive. The implemented
brief and critique templates turn that hypothesis into a testable process: select a
specific hierarchy problem, predict the result of one change, capture again at the
same viewport, and record whether it helped. Do not promise a fixed iteration count.

Next sample: independent design engineering blogs, HN threads, GitHub issue failures,
and team case studies, including reports where reference-based iteration failed.
