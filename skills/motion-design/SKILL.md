# Motion design

For each motion, identify trigger, purpose, frequency, duration/easing, interruption
behavior and reduced-motion alternative. Read [motion guidance](../../knowledge/motion/recipes.md).
A frequent task should remain fast; a narrative moment can take more time.

Motion can explain cause, spatial continuity, progress or mood. The chosen aesthetic
governs expressiveness. Do not require an entrance, parallax or animation library on
every page. Preserve user scroll control and keep essential content present without
animation. Avoid multiple independent loops competing for attention.

Test keyboard and pointer activation, rapid repeated input, low-power rendering and
reduced-motion. Screenshots alone do not verify temporal quality. Record which
transitions were actually exercised; only report a performance problem as measured
when you captured appropriate profiling evidence.
