# Redesign

Capture the incumbent interface and exercise its primary task before editing.
List routes, content, integration boundaries and states to preserve. Check existing
tokens and brand assets. A request to polish a component does not authorize replacing
the whole product identity.

Distinguish functional defects, hierarchy problems and aesthetic mismatch.
Select a direction through [creative direction](../creative-direction/SKILL.md).
For a broad redesign, replace the inconsistent visual rules coherently; don't retain
half of a discarded design merely to minimize line changes.

Implement one representative route and shared components, then carry the same tokens
and state patterns across the remaining authorized pages. Recheck interaction behavior.
Compare before/after at identical viewports. Report improvements as observed changes,
not a claim of conversion lift without supporting data.
