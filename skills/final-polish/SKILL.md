# Final polish

Read the brief and outstanding critique. Resolve consequential unfinished states
before adjusting cosmetic details. Check image crops, repeated alignments, text
wrapping, focus, disabled/loading states, navigation destinations and mobile spacing.

Use [visual audit](../visual-audit/SKILL.md) for the affected routes. Run the build
and relevant tests. Verify assets are available and appropriately licensed; remove
accidental placeholders and label intentional demo data. Do not invent a metric,
testimonial or production integration to make a demo appear complete.

Deliver the working artifact, commands, actual validation and remaining limits.
Use concise evidence. Do not claim browser verification if only source code was
read, or claim independent benchmark success from an authored showcase.
