# Combining styles deliberately

Treat aesthetic, composition, product category, density and motion as separate axes.
An enterprise dashboard can be visually quiet or expressive while retaining the same
interaction contract. A bento grid is a composition, not a complete brand.

Choose a dominant rule system, then assign the secondary influence a bounded role.
Record what each controls and what remains shared. Start with one primary influence
and one secondary influence, expanding only when the brief justifies it.

| Combination | Division of responsibility | Conflict to resolve | Test |
| --- | --- | --- | --- |
| Swiss + brutalist | Swiss alignment and hierarchy; brutalist borders and blunt type contrast | Structure versus apparent disorder | Reading order remains clear when decoration is hidden |
| Luxury editorial + minimalism | Editorial image/type pacing; minimal navigation and controls | Sparse content versus missing purchase information | Price, delivery and action remain discoverable |
| Industrial + SaaS | Industrial surfaces; utilitarian forms and tables | Expressive labels versus precise task language | Primary workflow is understandable without decoding metaphors |
| Retro + analytics | Retro chrome; modern data formatting and keyboard patterns | Nostalgia versus dense readability | Tables survive zoom and mobile adaptation |
| Maximalism + structured navigation | Expressive section art; one conventional navigation grammar | Abundance versus competing calls to action | Date/location/action are identifiable in one scan |

Keep a shared spacing rhythm, body-text system and interaction vocabulary. Variation
can be intentional: a bold campaign hero can lead into a quiet schedule. Explain the
change through content, not arbitrary aesthetic switching. Test the mobile and
reduced-motion versions as complete compositions in their own right.
