# Diagnose the failure, not the effect

| Signal | Evidence to seek | Valid exception | Targeted repair |
| --- | --- | --- | --- |
| Repeated card grid | Different content forced into identical structures | Comparable plans or products | Match layout to information type |
| Gradient or glow | Poor contrast, unrelated mood, competing focus | Expressive brand or purposeful visualization | Simplify the layer or relocate text |
| Empty oversized hero | Main task and proof pushed beyond reach | Deliberate product story with clear navigation | Reduce dead space or show actual product evidence |
| Generic copy | Claims could describe unrelated products | Shared utility labels | Name audience, task and factual result |
| Incoherent type | Competing display voices or unreadable metrics | Intentional editorial contrast | Clarify roles and correct line-height/measure |
| Arbitrary radii/shadows | Equivalent components imply different hierarchy | Different materials or elevation levels | Map treatment to role |
| Fake product visual | Controls/data cannot explain what the product does | Clearly labeled conceptual illustration | Show a working task or honest static diagram |
| Excessive motion | Repeated distraction, obscured controls, poor reduced-motion state | Purposeful entertainment or narrative | Keep a primary rhythm and remove interference |
| Mobile imbalance | Clipped text, orphan controls, accidental page scroll | Named two-dimensional data region | Recompose by priority |

Objective defects: failed task, unintended page overflow, missing control name,
verified contrast failure, runtime error. Subjective concerns: weak rhythm, derivative
identity, excessive quietness, insufficient tension. Report them separately.

A finding needs location, observed evidence, consequence and an expected benefit
from the fix. An effect-name ban is not an explanation. After correction, look again
at the intended style: a maximalist festival should not quietly become an enterprise
dashboard. Compare against the brief, not a default house aesthetic.
